# Accessibility

Target: **WCAG 2.2 AA**. These are requirements, not aspirations — oxlint's `jsx-a11y` plugin
catches the mechanical subset, and the rest is on review.

## Semantics first

A real `<button>`, `<a>`, `<table>`, `<nav>`, `<main>`. An ARIA role is what you reach for when
no element carries the meaning — never a substitute for the element that does.

```tsx
// ❌ not focusable, not keyboard operable, not announced
<div onClick={select}>…</div>

// ✅
<button type="button" onClick={select}>…</button>
```

Every page has exactly one `<h1>`, and heading levels never skip.

## Keyboard

Everything reachable by mouse is reachable by keyboard, in a sensible order.

- No positive `tabIndex`. `tabIndex={-1}` only for programmatic focus targets.
- `Escape` closes a dialog; focus returns to whatever opened it.
- Focus is trapped inside an open modal.
- The skip link (`.skip-link`) is the first focusable element on the page.

Focus is **always visible** — `:focus-visible` gets a 2 px `ring` outline globally. Never
`outline: none` without an equally visible replacement.

## Labelling

Every control has an accessible name: a `<Label htmlFor>`, an `aria-label`, or
`aria-labelledby`. An icon-only button always carries `aria-label`.

Form errors are tied to their field with `aria-describedby` and the field is marked
`aria-invalid`. The error text is a sibling, not a `title`.

## Status and live regions

Async results are announced: a toast container is a live region, and a table that reloads sets
`aria-busy`. Never communicate a state change by colour alone — pair it with text or an icon.

## The world map

An SVG data visualisation is not exempt.

- The `<svg>` has `role="img"` and an `aria-label` describing what is plotted.
- Each dot is a real `<button>` (or has `role="button"` with `tabIndex={0}` and key handlers),
  with an accessible name of the form "Germany, 22 000 t, 3 facilities".
- The same information is available **outside** the map — the summary's "by country" list is
  the non-visual equivalent, not a nice-to-have.
- Dot size carries magnitude, but colour never carries meaning on its own.

## Motion and contrast

`prefers-reduced-motion: reduce` is honoured globally in `styles/index.css`; do not
re-introduce an unconditional animation.

All three themes must clear 4.5:1 for body text and 3:1 for large text and UI boundaries. `dim`
is the one most likely to fail — check it when adding a token.

## Cross-browser

Chromium, Firefox and WebKit. No vendor-only API without a guarded fallback. `oklch` and
`@custom-variant` are baseline for this project's stated browser support; anything newer needs
a note in `DESIGN.md`.
