# Code style

Full prose lives in [`CODE_STYLE.md`](../../CODE_STYLE.md). This file is the operational half.

## Four commands

```bash
pnpm lint        # oxlint          — correctness
pnpm check       # biome           — formatting + import order
pnpm typecheck   # tsc --noEmit    — types
pnpm test        # vitest          — behaviour
pnpm verify      # lint + check + typecheck
```

"Green" means every one exited zero. Report which failed, never "should be fine".

## One linter, one formatter — on purpose

Biome is a linter **and** a formatter. Running both its linter and oxlint would report the same
problem twice under two different rule names, so:

- **oxlint is the only linter.** `.oxlintrc.json`, with the `react`, `typescript`, `import`,
  `jsx-a11y`, `oxc`, `promise` and `unicorn` plugins.
- **Biome is the formatter only.** `"linter": { "enabled": false }` in `biome.json` is
  deliberate — do not turn it on.

Auto-fix:

```bash
pnpm lint:fix     # oxlint --fix
pnpm check:fix    # biome check --write
```

A `PostToolUse` hook already runs `biome format --write` after every edit, so formatting
should rarely fail in the first place.

## Common oxlint violations

| Rule | Fix |
|---|---|
| `typescript/no-explicit-any` | Parse it with a schema, or use `unknown` + narrowing. |
| `typescript/consistent-type-imports` | `import type { X }` for type-only imports. |
| `react/no-array-index-key` | Key by a domain id. |
| `import/no-cycle` | Two slices importing each other → push the shared part one layer down. |
| `jsx-a11y/*` | Use the semantic element, or add the label. See `a11y.md`. |
| `no-console` | Allowed only in `src/app/mocks/**` and config files. |
| `unicorn/no-array-sort` | Use `toSorted()` — `sort()` mutates. Same for `toReversed()`. |

## What is ignored, and why

`.claude/**` (templates hold `__Placeholder__` identifiers), `src/routeTree.gen.ts` (generated by
the router plugin), `public/mockServiceWorker.js` (vendored by MSW), `dist/`, `.output/`,
`.tanstack/`, `storybook-static/`. Never edit a generated file to satisfy a
gate — fix the source or widen the ignore, and say which.

## Formatting settings

Single quotes, no semicolons, trailing commas, 100-column lines, 2-space indent, arrow
parentheses omitted for a single argument. These are set once in `biome.json`; do not restate
them in an editor config that can drift.
