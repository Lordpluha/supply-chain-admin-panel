## How to read this Storybook

**Theme** and **Language** in the toolbar are global. They change the real `data-theme`
attribute and the real i18next instance, so what you see is what the panel does — not a
Storybook approximation.

Every story is also a test. `pnpm test:stories` renders them in Chromium with the
accessibility addon set to `error`, so a missing label or a bad contrast ratio fails the run
rather than sitting in a panel.

| Command | What it does |
| --- | --- |
| `pnpm storybook` | This, on port 6006. Also serves the MCP endpoint at `/mcp`. |
| `pnpm storybook:build` | Static build into `storybook-static/`. |
| `pnpm test:stories` | Runs every story as a browser test. |

## The rules behind it

- `.claude/rules/styling.md` — the three themes, why nothing is hard-coded
- `.claude/rules/a11y.md` — the WCAG 2.2 AA contract, including the map
- `DESIGN.md` — the visual and interaction intent
- `CODE_STYLE.md` — naming, size limits, what never appears in a diff

`src/shared/ui/**` is vendored verbatim from shadcn and is the one place exempt from the
file-size rule: `shadcn add` must be able to overwrite it cleanly.
